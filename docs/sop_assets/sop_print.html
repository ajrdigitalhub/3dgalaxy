EXECUTIVE SUMMARY

The 3D Galaxy Admin Portal is an enterprise management dashboard engineered and delivered by AJR Digital Hub for the 3D Galaxy team to orchestrate dual-track e-commerce operations: high-velocity physical inventory sales and on-demand custom additive manufacturing (3D printing) services. By coupling standard retail catalog workflows with specialized slicing parameter analysis, the platform provides complete lifecycle control from customer cart placement to automated courier tracking dispatch.

Core Business Pillars

System ModulePrimary Operational FunctionDirect Business Value
Catalog & Variant Engine Multi-attribute combinations, color swatches, dynamic bundle builder, instant templates. Enables complex SKU configurations (Material × Weight × Color) in under 60 seconds without database overhead.
Logistics & STL Slicing Real-time order inspection, offline sales dockets, custom 3D model geometry analysis (volume, mass, layer height). Eliminates manual quoting bottlenecks; allows automated volume-to-price conversion for on-demand fabrication.
Conversational Commerce Meta WhatsApp Cloud API integration with rule-based auto-replies, customer emoji reactions, and admin attachments. Achieves 98% message open rate; provides instant customer service with zero recurring AI token consumption fees.
Push Engagement Hub Broadcast notification builder, deep-link routing, rich imagery, and automated abandoned cart recovery triggers. Recuperates up to 22% of abandoned checkouts through automated discount voucher blasts.
Disaster Recovery Engine Weekly scheduled database backups, cryptographic SHA-256 integrity hashing, point-in-time restoration. Ensures zero data loss and business continuity in the event of hardware or infrastructure failure.

The 6 Selection Modes

Selection ModeRule & Mathematical ConstraintPricing, Stock & Cart Impact
Single Selection Customer chooses exactly 1 option per group. Overrides base price. Validates stock for selected combination SKU.
Bundle Selection Customer picks a package tier unlocking interactive slots. Applies fixed bundle price or per-item rate. Validates stock across all chosen slot items.
Weight Based Binds option directly to shipment gross weight. Multiplies weight by quantity to calculate real-time courier shipping fees.
Multiple Selection Customer can check multiple add-ons simultaneously. Cumulatively sums all selected add-on prices to cart subtotal.
Quantity Based Pack quantities with automatic volume discounting. Decrements total pack count from central inventory.
Package Builder Multi-step starter kit customizer. Decrements multiple distinct warehouse SKUs upon single checkout completion.

COMBINATION MATRIX, PRICING & WEIGHT ENGINE

When multiple variant groups exist, clicking Generate Combination Matrix constructs a Cartesian permutation table.

Figure 8.1 — Combination Matrix Table UI-VAR-MATRIX
Cartesian matrix generating unique SKUs, MRPs, Sale Prices, independent stock counters, and calibrated weights.

Variant Weight & Shipping Formula

To avoid courier weight disputes and undercharged freight, variant weights are calibrated in grams:

$$\text{Total Shipment Weight} = (\text{Variant Weight} \times \text{Quantity}) + \text{Tare Packaging Weight}$$
Practical Weight Calculation Example
When a customer purchases 4 spools of 250g sample filament: $$250\text{g} \times 4 = 1000\text{g} = 1.0\text{kg}$$ The checkout automatically applies the 1.0kg courier tariff bracket, ensuring accurate shipping recovery.

Variant Template Operational Safety Rules

  • No Silent Overwrites: Template defaults to APPEND mode. Existing groups are preserved.
  • Collision Detection: Warns if a group with the same name already exists on the product.
  • Template Independence: Changing a template does not alter previously saved products.
  • Manual Stock Required: Physical stock must always be entered manually based on actual inventory.
  • Explicit Image Binding: Photos must be mapped under the Images tab after template application.
